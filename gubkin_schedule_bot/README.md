# Бот расписания РГУ им. Губкина — группа ГМ-26-11 (факультет геологии)

Выгружает расписание группы с публичного API `lk.gubkin.ru/schedule` (логин не нужен):
Telegram-бот и консольный скрипт для выгрузки в файлы.

## Установка

```bash
cd gubkin_schedule_bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

## Выгрузка всего расписания в файлы

```bash
python export.py                                   # ГМ-26-11, весь текущий семестр
python export.py --from 2026-09-01 --to 2027-01-31 --out out/
python export.py --group ГМ-26-12                  # другая группа
```

В папке `out/` появятся:

| файл   | для чего                                                    |
|--------|-------------------------------------------------------------|
| `.ics` | импорт в Google Календарь / Apple Calendar / Outlook        |
| `.csv` | открыть в Excel (разделитель `;`, UTF-8 с BOM)               |
| `.json`| данные для своих программ                                   |
| `.txt` | читаемый текст по дням                                      |

В каждой паре: дата, время, предмет, тип (лекция/семинар/лаба), аудитория, преподаватель,
подгруппа, тип недели (верхняя/нижняя), отмена, замены аудитории/преподавателя и переносы.

## Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Запустите:
   ```bash
   BOT_TOKEN=123456:ABC... python bot.py
   ```

Команды: `/today`, `/tomorrow`, `/week`, `/next`, `/date 15.10.2026`,
`/all` — прислать всё расписание семестра файлами (ICS, CSV, JSON, TXT),
`/captcha` — если сайт попросил капчу (бот пришлёт картинку, ответьте кодом).

`/subscribe` — бот будет каждое утро в 7:00 (МСК) присылать расписание на день
(в дни без пар не пишет), `/unsubscribe` — отписаться.

Необязательные переменные окружения: `GROUP_CODE` (по умолчанию `ГМ-26-11`),
`GROUP_ID` (id группы на сайте — пропускает поиск), `FACULTY_HINT` (по умолчанию `геолог`).

## Дописать самому — задания для начинающих

Файл [`my_commands.py`](my_commands.py) — шесть заданий на обычном Python (строки, списки,
условия, циклы, словари, функции). Каждое задание — одна функция, к ней уже подключена
команда бота: `/about`, `/count`, `/lectures` и `/labs`, `/first`, `/stats`, `/free`.
Пока функция не написана, бот отвечает «команда ещё не готова».

```bash
python check.py      # проверка: ✅ сделано / ❌ что не так
```

Порядок: прочитать условие → написать код → `python check.py` → перезапустить бота → проверить в Telegram.

**Как добавить совсем новую команду**, например `/hello`:
1. В `my_commands.py` напишите функцию `def hello_text(): return "Привет!"`.
2. В `bot.py` рядом с `cmd_about` добавьте:
   ```python
   async def cmd_hello(update, ctx):
       await _reply_my(update, my.hello_text(), "hello_text")
   ```
3. В `main()` рядом с остальными `add_handler` добавьте:
   `app.add_handler(CommandHandler("hello", cmd_hello))`

## Как это работает

- Группа ищется по коду: сначала на факультетах с «геолог» в названии, потом на остальных
  (`act=list&method=getFaculties` → `getFacultyGroups`).
- Расписание берётся по неделям (`act=schedule&date=Д-М-ГГГГ&groupId=…`) за весь семестр:
  осенний — 1 сентября – 31 января, весенний — 1 февраля – 30 июня.
- Сайт требует cookie сессии с `/schedule/` и иногда отвечает капчей (HTTP 429) —
  тогда пройдите капчу через `/captcha` в боте или в браузере.
