# Бот расписания РГУ им. Губкина — факультеты геологии, АиВТ, химии и экологии, экономики и управления, разработки месторождений, трубопроводного транспорта

Выгружает расписание группы с публичного API `lk.gubkin.ru/schedule` (логин не нужен):
Telegram-бот и консольный скрипт для выгрузки в файлы.

## Установка

```bash
cd gubkin_schedule_bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

## Выгрузка всего расписания в файлы

```bash
python export.py                                   # ГМ-26-11, весь текущий семестр
python export.py --from 2026-09-01 --to 2027-01-31 --out out/
python export.py --group ГМ-26-12                  # другая группа
```

В папке `out/` появятся:

| файл   | для чего                                                    |
|--------|-------------------------------------------------------------|
| `.ics` | импорт в Google Календарь / Apple Calendar / Outlook        |
| `.csv` | открыть в Excel (разделитель `;`, UTF-8 с BOM)               |
| `.json`| данные для своих программ                                   |
| `.txt` | читаемый текст по дням                                      |

В каждой паре: дата, время, предмет, тип (лекция/семинар/лаба), аудитория, преподаватель,
подгруппа, тип недели (верхняя/нижняя), отмена, замены аудитории/преподавателя и переносы.

## Быстрый запуск на Windows

1. Создайте в папке `gubkin_schedule_bot` файл `token.txt` и вставьте в него токен от @BotFather.
   (Если Telegram открывается только через прокси — файл `proxy.txt` с адресом, например `socks5://127.0.0.1:12334`.)
2. Запускайте бота двойным кликом по `start_bot.bat`: он сам скачает обновления (`git pull`) и запустит бота.
   Остановить — закрыть окно.

Файлы `token.txt` и `proxy.txt` не попадают в git.

**Статистика для администратора.** Отправьте боту `/myid`, сохраните этот номер в файл `admin.txt`
рядом с `bot.py` и перезапустите бота. Тогда `/users` покажет, кто пользуется ботом
(имя, @username, сколько запросов, когда последний), а о каждом новом человеке бот напишет вам.
Данные хранятся в `users.json` на вашем компьютере и в git не попадают.

## Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Запустите:
   ```bash
   BOT_TOKEN=123456:ABC... python bot.py
   ```

Каждый пользователь выбирает факультет и группу: кнопка «👥 Моя группа», команда `/group`
или просто код группы сообщением (`ГМ-26-12`). Факультеты перечислены в `FACULTIES` в `bot.py`
(чтобы добавить факультет — допишите строку). Списки групп и их расписание присылает ноутбук
(`sync.py`), см. ниже.

Команды: `/today`, `/tomorrow`, `/week`, `/next`, `/date 15.10.2026`, `/group`,
`/all` — прислать всё расписание семестра файлами (ICS, CSV, JSON, TXT),
`/captcha` — если сайт попросил капчу (бот пришлёт картинку, ответьте кодом).

`/subscribe` — бот будет каждое утро в 7:00 (МСК) присылать расписание на день
(в дни без пар не пишет), `/unsubscribe` — отписаться.

Необязательные переменные окружения: `GROUP_CODE` (группа по умолчанию — по ней ищется
факультет и её получили те, кто пользовался ботом до выбора групп; `ГМ-26-11`),
`GROUP_ID` (id группы на сайте — пропускает поиск), `FACULTY_HINT` (по умолчанию `геолог`).

## Команды на простом Python — `my_commands.py`

Команды `/about`, `/count`, `/lectures` и `/labs`, `/first`, `/stats`, `/free` написаны в
[`my_commands.py`](my_commands.py) на обычном Python (строки, списки, условия, циклы, словари),
с пояснениями над каждой функцией — их удобно читать и менять.

```bash
python check.py      # проверка, что функции работают правильно
```

**Как добавить совсем новую команду**, например `/hello`:
1. В `my_commands.py` напишите функцию `def hello_text(): return "Привет!"`.
2. В `bot.py` рядом с `cmd_about` добавьте:
   ```python
   async def cmd_hello(update, ctx):
       await _reply_my(update, my.hello_text(), "hello_text")
   ```
3. В `main()` рядом с остальными `add_handler` добавьте:
   `app.add_handler(CommandHandler("hello", cmd_hello))`

## Как это работает

- Группа ищется по коду: сначала на факультетах с «геолог» в названии, потом на остальных
  (`act=list&method=getFaculties` → `getFacultyGroups`).
- Расписание берётся по неделям (`act=schedule&date=Д-М-ГГГГ&groupId=…`) за весь семестр:
  осенний — 1 сентября – 31 января, весенний — 1 февраля – 30 июня.
- Сайт требует cookie сессии с `/schedule/` и иногда отвечает капчей (HTTP 429) —
  тогда пройдите капчу через `/captcha` в боте или в браузере.

## Сервер + ноутбук (sync)

Сайт Губкина не пускает серверы хостингов, а Telegram заблокирован в России. Поэтому:

- бот работает на сервере и ходит в Telegram через свой Cloudflare Worker
  (`deploy/tg-relay-worker.js`, подключается `deploy/relay.sh`);
- расписание скачивает ноутбук (домашний интернет сайт пускает) и отправляет на сервер:
  `sync.py`, бот на сервере запущен с `GUBKIN_OFFLINE=1` и отвечает по присланному файлу.

На ноутбуке: `sync_setup.bat` — один раз (ключ для входа на сервер, настройка сервера,
автозапуск: через 2 минуты после входа в Windows и каждые 3 часа, без окон).
`sync_now.bat` — обновить вручную, с вводом капчи. `sync_off.bat` — убрать из автозапуска.
Журнал — `sync.log`. Если нужна капча или расписание давно не обновлялось, бот напишет администратору.
