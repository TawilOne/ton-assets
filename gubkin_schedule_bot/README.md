# Бот мини-игр (шахматы)

Telegram-бот с мини-приложением: шахматы онлайн с другими игроками, рейтинг Эло, игра с ботом
(Stockfish, 3 уровня, без рейтинга), приглашение друга по ссылке, уведомления «кто-то ищет игру»
и «соперник нашёлся».

**Расписание, карта, «Где пара», столовая и любые обращения к сайту университета удалены полностью
(28.10.2026) по требованию университета. Возвращать их нельзя.**

## Из чего состоит
- `bot.py` — бот: `/start`, `/games`, `/settings` (язык), ссылки-приглашения в партию, уведомления по шахматам;
  для администратора — `/users` (статистика), `/broadcast` (рассылка текста, фото или альбома), `/myid`.
  На старые команды и кнопки расписания бот отвечает, что их больше нет, и убирает старую нижнюю панель.
- `games.py` — сервер игр (aiohttp + python-chess, SQLite `games.db`, проверка подписи Telegram).
- `i18n.py` — тексты на русском, английском и французском.
- `../docs/games.html` — мини-приложение с шахматами, `../docs/admin.html` — статистика для администратора.
- `../deploy/` — установка и обновление на сервере (`update.sh`).
