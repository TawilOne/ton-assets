# Контекст проекта (для продолжения в новом чате)

Telegram-бот расписания РГУ нефти и газа им. Губкина для **всех групп факультета геологии**
, **автоматики и вычислительной техники**, **химической технологии и экологии**, **экономики и управления**, **разработки нефтяных и газовых
месторождений**, **проектирования, сооружения и эксплуатации систем трубопроводного транспорта**,
**инженерной механики**, **комплексной безопасности ТЭК**, **международного энергетического
бизнеса**, **гуманитарного образования**
(`FACULTIES` в bot.py — факультет ищется на сайте по ВСЕМ словам из hint; каждый выбирает факультет → курс → группу:
«👥 Моя группа», /group или код группы сообщением)
и мини-приложение «Где пара» с картами этажей. Автор — начинающий (Windows, PowerShell, VS Code, iPhone),
всё общение — на русском, объяснять по шагам и просто.

## Где что лежит (ветка `claude/rgu-gubkina-schedule-bot-snqhke`)
- `gubkin_schedule_bot/` — бот: `bot.py` (команды, кнопки, рассылка в 7:00, админ-статистика `/users`),
  `gubkin_api.py` (API lk.gubkin.ru, кэш, капча, offline-режим), `schedule.py` (разбор, форматы),
  `sync.py` + `sync_*.bat` (ноутбук скачивает расписание и шлёт на сервер), тесты `test_schedule.py`.
- `docs/` — мини-приложение на GitHub Pages (`https://tawilone.github.io/ton-assets/`): `index.html`,
  `campus.js`, `plans/main-1..8.svg`, `rooms.json`, `plans.json`.
- `floorplans/v2/` — генератор карт этажей главного корпуса: `rectify.py` (выпрямление фото),
  `building.py`/`floors.py` (форма здания), `detect_walls.py` (стены с фото), `build2.py` (сборка SVG),
  `check_overlay.py` (сверка с фото). `floorplans/campus.py` — карта двора (в приложении сейчас скрыта).
- `deploy/` — сервер: `install.sh`, `update.sh`, `relay.sh`, `tg-relay-worker.js`, `doctor.sh`.

## Как всё работает сейчас
- Бот живёт на VPS FirstVDS в Москве (`root@153.76.167.68`, Ubuntu 24.04, служба `gubkin-bot`).
- Telegram в РФ заблокирован → бот ходит через **Cloudflare Worker** (адрес — на сервере в /etc/systemd/system/gubkin-bot.service.d/relay.conf)
  (переменная `TG_API_BASE`, включено `deploy/relay.sh`).
- Сайт Губкина **не пускает серверы хостингов** (HTTPS с VPS не открывается) → бот на сервере в режиме
  `GUBKIN_OFFLINE=1`, расписание присылает **ноутбук** (`sync.py`, задача Windows `GubkinSync`:
  через 2 мин после входа и каждые 3 часа, тихо; по ssh-ключу `~/.ssh/gubkin_sync_ed25519`).
- Обновить бота на сервере (из PowerShell): `ssh root@153.76.167.68 "bash /opt/gubkin-bot/deploy/update.sh"`.
- Группы: ноутбук раз в сутки качает списки групп факультетов (`groups.json`, формат `{"faculties": [...]}`) и по плану —
  расписание: выбранные пользователями группы — ближайшие 3 недели каждый раз, их дальние недели — раз в 3 дня
  (`FAR_AGE`), остальные группы — ОДНА неделя (пн–чт текущая, пт–вс следующая). Чем меньше запросов, тем реже
  сайт просит капчу. По расписанию — не дольше 11 минут за запуск и не больше 60 запросов «чужих» групп;
  вручную (`sync_now.bat`) — **без лимита по времени**, качает весь план, по ходу раз в 10 мин отправляет
  скачанное на сервер и держит `sync.lock` свежим. Кто какую группу выбрал — `user_groups.json` на сервере
  (ноутбук читает его по ssh). Кэш хранится ужатым (`schedule.slim_week`). Прежние пользователи при первом
  запуске получили ГМ-26-11.
- Защита данных: `guard.py` ловит подмену расписания (персонажи, эмодзи, ссылки, невозможное время) — бот
  такое не покажет, а напишет «произошла ошибка» и сигналит админу; `sync.py` не сохраняет подозрительные
  недели, оставляет прежние. Сохранение атомарное (`write_atomic`). Капча: своя картинка на каждую попытку,
  перевод раскладки EN→RU; если картинку не удалось записать/открыть (Windows [Errno 22]) — пишем во
  временную папку и не роняем загрузку.
- Отмены и переносы: `changes_job` (раз в 3 мин, только offline) сравнивает новое расписание с прошлым
  (`changes_seen.json`) на неделю вперёд и пишет тем, кто выбрал группу. Новая неделя/группа — молча; ночью
  (23–7) не пишет, сообщение придёт утром.
- Мини-приложение обновляется само (GitHub Pages, до ~10 мин кэша); ссылка из бота меняется раз в 5 мин.

## Секреты — никогда не писать в чат и в git
Токен бота, пароль сервера, VPN-ключ. Токен уже дважды утекал на скриншотах — при утечке `/revoke` в BotFather.
