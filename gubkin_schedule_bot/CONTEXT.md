# Контекст проекта (для продолжения в новом чате)

Telegram-бот расписания РГУ нефти и газа им. Губкина для **всех групп факультета геологии**
и **автоматики и вычислительной техники** (`FACULTIES` в bot.py; каждый выбирает факультет → курс → группу:
«👥 Моя группа», /group или код группы сообщением)
и мини-приложение «Где пара» с картами этажей. Автор — начинающий (Windows, PowerShell, VS Code, iPhone),
всё общение — на русском, объяснять по шагам и просто.

## Где что лежит (ветка `claude/rgu-gubkina-schedule-bot-snqhke`)
- `gubkin_schedule_bot/` — бот: `bot.py` (команды, кнопки, рассылка в 7:00, админ-статистика `/users`),
  `gubkin_api.py` (API lk.gubkin.ru, кэш, капча, offline-режим), `schedule.py` (разбор, форматы),
  `sync.py` + `sync_*.bat` (ноутбук скачивает расписание и шлёт на сервер), тесты `test_schedule.py`.
- `docs/` — мини-приложение на GitHub Pages (`https://tawilone.github.io/ton-assets/`): `index.html`,
  `campus.js`, `plans/main-1..8.svg`, `rooms.json`, `plans.json`.
- `floorplans/v2/` — генератор карт этажей главного корпуса: `rectify.py` (выпрямление фото),
  `building.py`/`floors.py` (форма здания), `detect_walls.py` (стены с фото), `build2.py` (сборка SVG),
  `check_overlay.py` (сверка с фото). `floorplans/campus.py` — карта двора (в приложении сейчас скрыта).
- `deploy/` — сервер: `install.sh`, `update.sh`, `relay.sh`, `tg-relay-worker.js`, `doctor.sh`.

## Как всё работает сейчас
- Бот живёт на VPS FirstVDS в Москве (`root@153.76.167.68`, Ubuntu 24.04, служба `gubkin-bot`).
- Telegram в РФ заблокирован → бот ходит через **Cloudflare Worker** `https://gubkin-tg.kirilgrigoryev11.workers.dev`
  (переменная `TG_API_BASE`, включено `deploy/relay.sh`).
- Сайт Губкина **не пускает серверы хостингов** (HTTPS с VPS не открывается) → бот на сервере в режиме
  `GUBKIN_OFFLINE=1`, расписание присылает **ноутбук** (`sync.py`, задача Windows `GubkinSync`:
  через 2 мин после входа и каждые 3 часа, тихо; по ssh-ключу `~/.ssh/gubkin_sync_ed25519`).
- Обновить бота на сервере (из PowerShell): `ssh root@153.76.167.68 "bash /opt/gubkin-bot/deploy/update.sh"`.
- Группы: ноутбук раз в сутки качает списки групп факультетов (`groups.json`, формат `{"faculties": [...]}`) и по плану —
  расписание: выбранные пользователями группы — весь семестр, остальные — текущая и следующая неделя
  (по расписанию не больше 60 таких запросов за раз; за запуск не дольше 11 минут). Кто какую группу выбрал —
  `user_groups.json` на сервере (ноутбук читает его по ssh). Кэш хранится ужатым (`schedule.slim_week`).
  Прежние пользователи при первом запуске получили ГМ-26-11.
- Мини-приложение обновляется само (GitHub Pages, до ~10 мин кэша); ссылка из бота меняется раз в 5 мин.
