# Контекст проекта

## Главное
28.10.2026 по требованию университета из проекта **полностью удалены**: скачивание данных с сайта
университета (`gubkin_api.py`, `sync.py` и задача Windows `GubkinSync` на ноутбуке), расписание,
уведомления об отменах, карта вуза и планы этажей, страница «Где пара», столовая.
**Никогда не возвращать их и не обращаться к сайту университета.** Тест `test_bot.py` проверяет,
что в коде нет адресов сайта и удалённых файлов.

## Что осталось
- Бот мини-игр (`bot.py`): шахматы, язык, статистика и рассылка для администратора.
- Сервер игр (`games.py`, служба `gubkin-games`, HTTPS через Caddy) и мини-приложение `docs/games.html`
  на GitHub Pages (`https://tawilone.github.io/ton-assets/`).
- Бот живёт на VPS (служба `gubkin-bot`), в Telegram ходит через Cloudflare Worker (relay.sh).
- Обновить сервер: `bash /opt/gubkin-bot/deploy/update.sh` — он же удаляет со сервера старые файлы
  расписания и выключает прокси, если он не нужен.

## Секреты — никогда не писать в чат и в git
Токен бота, пароль сервера, VPN-ключ.
