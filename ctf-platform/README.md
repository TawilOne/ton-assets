# 🛡 RootCamp — своя CTF-платформа

Платформа для тренировки пентеста в духе CTF: категории, задания, сдача флагов,
«первая кровь», рейтинг, профили и админка для своих заданий.

## Запуск

```bash
cp .env.example .env        # задай пароль администратора
docker compose up -d --build
```

Открой http://localhost:8000. Администратор: логин `admin`, пароль из `ADMIN_PASSWORD`.

Без Docker: `pip install -r requirements.txt && ADMIN_PASSWORD=... python app.py`.

## Что есть

- **11 встроенных заданий**: веб (4 встроенные лабы), крипта (4), стеганография, форензика, реверс.
- **Флаги уникальны для каждой установки.** Они выводятся из случайного `data/secret.key`, поэтому в исходниках их нет и подсмотреть нельзя.
- **Первая кровь**, счётчик решений, рейтинг, профиль со статистикой.
- **Админка** (`/admin`): создание и редактирование заданий, загрузка файлов, поле «Адрес / IP» для машин, скрытие заданий.
- Флаги хранятся как SHA-256, есть CSRF-защита и лимит 10 попыток в минуту.

## Свои задания и машины

В админке нажми «Новое задание», выбери категорию, впиши описание и флаг, при необходимости приложи файл.

Для категории **«Машины»** подними уязвимую цель отдельно и впиши её адрес. Целью может быть,
например, `vuln-tg-bot` из соседней папки или контейнер из Vulhub / DVWA. Флаг возьми из этой цели.

## Сброс

`docker compose down -v` удалит базу, пользователей и сгенерирует новые флаги.

## Важно

Встроенные лабы `/lab/*` уязвимы намеренно, но безопасны для сервера: в них нет RCE и доступа к файлам.
Для публичного запуска поставь перед платформой HTTPS (nginx или Caddy).
