# Планы этажей для мини-приложения «Где пара»

Карта этажа — векторная схема (`docs/plans/main-N.svg`): ровные стены, коридоры и ячейки кабинетов,
без значков с плана эвакуации.

1. `ocr.py`, `ocr2.py` — распознают номера кабинетов на фото планов эвакуации
   (RapidOCR: `pip install rapidocr-onnxruntime pillow`), `build.py` собирает из этого
   позиции номеров → `rooms_ocr.json`.
2. `v2/rectify.py` — выпрямляет фото: по углам крыльев и центральной части (замерены вручную)
   каждое фото переводится в общую систему координат, где все этажи совпадают.
3. `v2/building.py` — общий «скелет» здания: крылья, коридоры, лестницы ЛМ-1…3, лифты ЛХ-1…2;
   `v2/floors.py` — что отличается по этажам (пристройки, БАА, холл 1 этажа).
4. `python floorplans/v2/build2.py` — раскладывает кабинеты по рядам (каждый не уже 16 ед.),
   пишет `docs/plans/main-N.svg`, `docs/rooms.json`, `docs/plans.json`.
   С аргументом-папкой рисует схему поверх выпрямленного фото (o{этаж}.jpg) — для сверки.

Чтобы поправить кабинет: позицию номера — в `rooms_ocr.json` (или `OVERRIDE` в `build2.py`),
форму этажа — в `v2/floors.py`, затем снова `build2.py`.
