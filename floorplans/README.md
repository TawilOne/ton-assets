# Планы этажей для мини-приложения «Где пара»

Карта этажа — векторная схема (`docs/plans/main-N.svg`): ровные стены, коридоры и ячейки кабинетов,
без значков с плана эвакуации.

1. `ocr.py`, `ocr2.py` — распознают номера кабинетов на фото планов эвакуации
   (RapidOCR: `pip install rapidocr-onnxruntime pillow`), `build.py` собирает из этого
   позиции номеров → `rooms_ocr.json`.
2. `zones.py` — форма этажа: ряды кабинетов, коридоры, пристройки (координаты 0–1000, сняты по фото).
3. `python floorplans/build_svg.py` — раскладывает кабинеты по рядам (граница — посередине между
   соседними номерами), рисует `docs/plans/main-N.svg` и пишет `docs/rooms.json`, `docs/plans.json`.

Чтобы поправить кабинет: позицию номера — в `rooms_ocr.json`, форму этажа — в `zones.py`,
затем снова `build_svg.py`.
