# Планы этажей для мини-приложения «Где пара»

Из фото планов эвакуации делаются тёмные карты (только стены) и координаты кабинетов.

1. `ocr.py`, `ocr2.py` — распознают номера кабинетов на фото (RapidOCR: `pip install rapidocr-onnxruntime pillow`).
   Пути к фото и номера этажей — в словаре `FILES`.
2. `build.py <папка docs> <папка превью>` — обрезает план, убирает значки и текст (`walls.py`),
   сохраняет `docs/plans/main-N.png` и записывает `docs/rooms.json`, `docs/plans.json`.

Ошибки распознавания правятся в `FIX` в `build.py` или вручную в `docs/mark.html`.
