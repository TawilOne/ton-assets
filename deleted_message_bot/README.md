# Бот для отслеживания удалённых сообщений

Подключается через **Настройки → Telegram для бизнеса → Автоматизация чатов**
и присылает вам в личку:

- 🗑 удалённые собеседником сообщения: текст, фото, видео, голосовые, кружки, стикеры, файлы;
- ✏️ изменённые сообщения в формате «было → стало».

> Нужен **Telegram Premium**: без него функции «Автоматизация чатов» нет.
> Бот видит только сообщения, пришедшие **после** подключения. Фото и видео
> с таймером (одноразовые) Telegram ботам не отдаёт.

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username.
2. Скопируйте токен (вида `123456:ABC...`).
3. В BotFather: `/mybots` → ваш бот → **Bot Settings → Business Mode → Turn on**.
   Без этого Telegram не даст выбрать бота в «Автоматизации чатов».

## 2. Запустить бота на сервере

Бот должен работать круглосуточно. С телефона проще всего так:

**Railway** (railway.app):
1. Войдите через GitHub → **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. В настройках сервиса: **Root Directory** = `deleted_message_bot` (Railway сам найдёт Dockerfile).
3. **Variables** → добавьте `BOT_TOKEN` = ваш токен.
4. Чтобы архив не терялся при перезапуске: **Add Volume** с путём `/data`.

Подойдёт любой хостинг с Docker или Python 3.10+ (Render, VPS, bothost и т. п.).

Локально: `pip install -r requirements.txt` и `BOT_TOKEN=... python bot.py`.

### Переменные окружения

| Переменная   | По умолчанию  | Что делает |
|--------------|---------------|------------|
| `BOT_TOKEN`  | —             | токен от BotFather (обязательно) |
| `DB_PATH`    | `messages.db` | где хранить архив сообщений |
| `KEEP_DAYS`  | `30`          | сколько дней хранить сообщения |
| `NOTIFY_OWN` | `false`       | `true`, чтобы сообщать и о ваших собственных удалениях/правках |
| `TZ`         | `Europe/Moscow` (в Docker) | часовой пояс для времени в отчётах |

## 3. Подключить

1. Напишите своему боту `/start`, иначе он не сможет вам писать.
2. **Настройки → Telegram для бизнеса → Автоматизация чатов** → введите `@username` бота.
3. Выберите «Все личные чаты, кроме…» или «Только выбранные чаты».
4. Бот пришлёт «✅ Бот подключён».

Учтите: бот хранит переписку на вашем сервере. Не давайте никому токен и доступ к базе.
